# AOOSTAR WTR MAX Screen Control Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Unreleased

### Added
- `aster-homelab` sensor provider for Proxmox VE (multiple standalone hosts or a cluster) and TrueNAS
  (JSON-RPC WebSocket API) with read-only credentials and certificate fingerprint pinning.
- Rotating homelab panels: summary, host, nodes, guests and TrueNAS, generated by `cfg/homelab/generate.py`.
- Systemd units and installer for Proxmox VE hosts in `deploy/pve`.
- Burn-in protection: `--pixel-shift`, `--wipe-interval` and `--off-hours`.
- Stale sensor detection with `--stale-after`: values of sensor files that are no longer updated are shown as `--`.
- Multiple `--sensor-path` options. Missing paths are picked up when they appear.
- Static `TEXT_` caption sensors and the optional panel field `requires`.
- `aster-sysinfo`: `system_uptime_short` sensor.
- Data protection: pool scrub status, TrueNAS replication / cloud sync / rsync / snapshot tasks,
  Proxmox guest backup age and backup job results, with a Data protection panel.
- Proxmox Backup Server: datastore usage and availability, verify / sync / prune / garbage
  collection jobs, with a Backup server panel and the `setup-pbs-token.sh` helper.

### Fixed
- Panel rotation stopped with "No active panel" when fewer panels were active than defined.
- Sensor keys removed from a sensor file were displayed forever.
- A single sensor with an invalid value prevented the whole panel from rendering.
- Watching a single sensor file stopped after the first atomic update.
- Text sensors without `value`, `unit`, `pic` or digit settings failed to load.
- `lcd-off.service` and `lcd-on.service` used `/usr/bin/asterctl` instead of the documented `/usr/local/bin/asterctl`.

## v0.2.0 - 2025-08-31
### Fixed
- Misplaced text sensors in custom panels ([#11](https://github.com/zehnm/aoostar-rs/issues/11)).
- Wrong start position for circular progress (fan) sensor using a counter-clockwise direction ([#12](https://github.com/zehnm/aoostar-rs/issues/12)).
- aster-sysinfo tool: make sensor file world-readable, create all parent directories.

### Added
- Simple sensor panel with a file-based data source ([#6](https://github.com/zehnm/aoostar-rs/issues/6)). 
- Initial support for fan-, progress-, & pointer-sensors ([#8](https://github.com/zehnm/aoostar-rs/pull/8)).
- Use [mdBook](https://rust-lang.github.io/mdBook/) for documentation and publish user guide to GitHub pages ([#10](https://github.com/zehnm/aoostar-rs/pull/10)).
- Initial `aster-sysinfo` tool for providing sensor values in a text file for `asterctl`.

### Changed
- Project structure using a Cargo workspace.
